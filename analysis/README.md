# 分析程式：「走這條！」的數據怎麼算出來的

所有數字都可以用政府開放資料重新算一次。

## 問題 → 指標
| 想回答的問題 | 指標 |
|---|---|
| 哪裡長者多？ | 各里 65 歲以上人口比例 |
| 哪裡曬？ | 每段人行道的估計樹冠覆蓋率（目標 ≥ 40%） |
| 哪裡長者容易被撞？ | 2023–2025 三年內，76 公尺內、路名一致，長者行人事故 ≥ 5 件（3–4 件列觀察） |
| 哪裡最需要這個工具？ | 超高齡（≥ 20%）＋樹冠覆蓋 < 40%；再依 75 歲以上比例排序 |

## 2. 執行
```bash
pip install -r requirements.txt
python run_all.py
```

| 步驟 | 做什麼 | 產出 |
|---|---|---|

| `03_accidents.py` | 行人事故統計、長者危險路口 | `output/accident_stats.txt`、`elder_hotspots.csv` |

方法參數（外推距離、門檻、密度條件）都集中在 `config.py`，可以改來做敏感度測試。

## 門檻與依據（v2：改用有出處的數值）
| 規則 | 原本（自訂） | 現在 | 依據 |
|---|---|---|---|
| 長者 | 65 歲 | 65 歲 | 《老人福利法》：年滿 65 歲 |
| 超高齡里 | 長者比例全市前 25% | **65 歲以上 ≥ 20%** | 聯合國定義，國發會沿用：≥ 20% 為超高齡社會 |
| 樹蔭足夠 | 每百公尺 ≥ 3 棵 | **估計樹冠覆蓋 ≥ 40%** | Ziter et al. 2019（PNAS）：樹冠覆蓋超過 40% 才有最大降溫效果 |
| 樹冠寬 | 未估計 | **8 m**（敏感度 5／10 m） | Hui, Jim & Zhang 2020：香港 30 種都市樹木多數樹冠寬 99 百分位約 10 m，且由胸徑推估的不確定性很大 → 用假設值並做敏感度測試 |
| 人行道外推 | 6 m | **5 m** | 樹冠半徑上限（10 m ÷ 2） |
| 都市里 | ≥ 5,000 人／km² | **≥ 1,500 人／km²** | 歐盟統計局 Degree of Urbanisation：都市中心 ≥ 1,500 人／km² |
| 路口範圍 | 50 m | **76 m（250 ft）** | 美國 FHWA 與路口安全研究常用的「與路口相關」範圍；研究也指出最好依路口調整 |
| 危險路口 | ≥ 2 件 | **2023–2025 三年內 ≥ 5 件＝危險、3–4 件＝觀察名單** | FHWA 建議用 3–5 年資料以排除隨機波動；三年 5 件約每年 1.7 件，與先前一年多 ≥ 3 件的嚴格度相當 |
| 優先里 | — | 超高齡＋覆蓋 < 40%，且 **75 歲以上比例前 25%** | 排序用、非標準；臺北市 113 年老人生活狀況調查：75 歲以上未上網比例較高 |
| 長者步行速率 | 50 m／分 | **0.8 m／秒（48 m／分）** | 《道路交通標誌標線號誌設置規則》第 231 條較低速率 0.8 m/s；交通部 115 年 3 月要求高齡熱點採較低速率 |
| 人行道 ≥ 500 m、人口 ≥ 1,000 | 同左 | 同左 | **操作性設定**（避免樣本太小），無外部標準 |

## 3. 驗證：過程中抓到並修正的問題
| 問題 | 怎麼發現 | 修正 |
|---|---|---|
| 新生南路東側被判「沒樹」 | 緊鄰大安森林公園，不合理 | 加入公園樹木 |
| 陽明山的里排名前三 | 山區森林不在行道樹資料，且非都市熱點 | 只比較人口密度 ≥ 5,000 人／km² 的都市里 |
| 公車乘客被算成行人 | 某熱點的長者其實在公車上 | 只取「行人」子類別 |
| 不同路口被湊成熱點 | 地址相距數公里、座標卻很近 | 加上「路名一致」檢查 |
| 「長者無照明事故 2 倍」 | 單月樣本；全年重算 17% vs 16% | 移除這項說法 |

交叉驗證：事故座標與交通局號誌路口清單比對，29 件中 27 件吻合。

## 4. 限制
- 未計騎樓、建築陰影與樹冠大小：「缺樹蔭」不等於「完全沒遮蔭」
- 人口為 115 年 9 月資料；事故為 2023–2025 三個完整年（2026 年只到資料更新月份，不納入門檻）
- 熱點里的長者事故率沒有比較高（每千位長者 0.94 件 vs 1.09 件（2025 年）），高溫與交通安全分開呈現，不宣稱因果
- `elder_hotspots.csv` 只含位置與件數，不含個別事故的日期、時間、年齡

## 注意
- 環境部 Cool Map 全國資料（data.gov.tw/dataset/177893）下載連結預設 `limit=1000`，會截斷且不含臺北市；改用臺北市資料集，或把網址改成 `limit=10000`。
- 路燈資料時間為 2017-07，之後新設或更換的路燈不在內；只代表有裝路燈，不保證燈有亮。
- 「較暗」門檻 `LIT_CUT_KW_PER_100M` 是示範路段的相對比較，不是照度標準。
